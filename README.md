# Fichas D&D

App instalable (PWA) para llevar fichas de personaje de D&D 5e con las reglas de 2024: tiradas, PG, espacios de conjuro, concentración, descansos, estados, edición e importación/exportación en JSON.

- Funciona sin conexión una vez instalada.
- Las fichas se guardan en el dispositivo (localStorage); nada se sube a ningún servidor.
- Para publicar una versión nueva: cambia `VERSION` en `sw.js`.
